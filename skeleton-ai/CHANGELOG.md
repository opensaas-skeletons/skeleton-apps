# Changelog

## v1.0.0 — Initial Release

### Features
- RAG-powered AI assistant with pgvector
- Local LLM support via Ollama (no API keys required)
- Multi-provider support: Ollama, Anthropic, OpenAI
- Source management with directory ingestion
- Smart text chunking (Markdown-aware, code-aware)
- Vector similarity search with configurable parameters
- Streaming chat with Server-Sent Events
- Markdown rendering with syntax highlighting
- Source citations with [1][2][3] notation
- Conversation management (create, rename, delete)
- Provider settings with model selection
- Retrieval tuning (top_k, similarity threshold, temperature)
- Custom system prompt configuration
- Export/import (AI Assistant Interop Standard v1.0)
- Bundled documentation for demo
- Docker Compose with Ollama service
