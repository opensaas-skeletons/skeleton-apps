# Changelog

## 1.0.0 (2024-01-01)

### Added
- Contact management with search, sort, and CSV import
- Company management with contact/deal associations
- Deal pipelines with drag-and-drop kanban board
- Multiple pipeline support with customizable stages
- Activity logging (calls, emails, meetings, notes, tasks)
- Dashboard with pipeline funnel, win rates, and activity charts
- JSON import/export (interop standard v1.0)
- API key and JWT authentication (disabled in dev)
- Docker Compose for one-command deployment
- Demo seed data
